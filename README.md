# Spark 共享单车日租赁量预测

使用 Spark 分析天气、日历信息与每日租车数量的关系，并预测每天的租赁总量。数据来自 UCI Bike Sharing，固定使用 2011—2012 年的 731 条日记录。

项目先建立均值和线性回归基线，再通过岭回归改善稳定性，增加天气与月份计算项表达变化规律，最后用树模型和近邻方法检验预测效果。所有方法使用相同的时间划分；比较结果后，对最终推荐模型重新进行误差分析。

## 一句命令复现

安装 **Python 3.10—3.12** 和 **Java 17**，确保 `python`、`java` 可在终端使用。在项目目录运行：

```bash
python reproduce.py
```

脚本自动准备 Python 依赖、下载并核对数据，完成训练、模型保存与恢复检查、结果核查和图表生成。Windows 会额外下载所需的 Hadoop 运行文件并校验完整性。无需预先下载模型，也无需启动虚拟机。依赖及下载来源见 [资源说明](NOTICE.md)。

## 主要结果

按时间顺序使用 511 天训练、110 天验证、110 天测试。扩展实验包含 9 类方法、23 组参数，并对 5 类方法进行两次历史窗口检查。

| 方案 | 验证 RMSE | 测试 RMSE | 测试 MAE | 测试 R² |
|---|---:|---:|---:|---:|
| 新增计算项的岭回归 | 842.67 | 1214.36 | 945.48 | 0.631 |
| 梯度提升树 | 783.86 | 1309.91 | 1093.56 | 0.571 |

单次验证集选出梯度提升树；结合历史窗口表现，最终展示方案选用新增计算项的岭回归。

全流程已在 Windows / Python 3.12 / Java 17 下验证，见 [复现验证](docs/复现验证.md)。

实验过程见 [实验说明](docs/实验说明.md)，选择依据见 [模型选择与误差分析](docs/模型选择与误差分析说明.md)。
