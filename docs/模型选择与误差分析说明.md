# 模型选择与误差分析说明

## 研究结论

本次综合历史比较推荐“新增计算项的岭回归”作为项目最终展示方案。该方案在天气与日历信息基础上，增加温度和湿度平方、温湿度乘积、温度与工作日标记的乘积，以及描述月份循环的正弦、余弦，共六个计算项。岭回归的控制强度沿用原验证集确定的0.01，模型包含33个系数。

原有按单次验证集RMSE选择的结果仍为梯度提升树。它的验证误差783.86最低。综合推荐根据已查看的历史结果进行，研究范围为当前单城两年数据；下一步使用新增日期和滚动验证检验结论。

### 单次验证表现

梯度提升树的验证RMSE为783.86，新增计算项岭回归为842.67，普通岭回归为925.67。该验证段覆盖2012年5月26日至9月12日，反映这一时间段上的拟合与预测表现。PPT保留原排名，并继续展示后续日期的结果。

### 测试期的预测准确性

新增计算项岭回归在110个测试日期上的RMSE、MAE和R²均为九个扩展系列中的最优结果。相对梯度提升树，RMSE降低7.29%，MAE降低13.54%，R²从0.571提高至0.631。相对普通岭回归，RMSE从1291.42降低到1214.36，MAE从988.85降低到945.48。

### 跨时段稳定性

两个较早窗口分别用前365天和前438天训练，再预测随后73天。第一窗口梯度提升树为1635.32，略低于新增计算项岭回归的1654.00；第二窗口普通岭回归为1193.14，低于新增计算项岭回归的1230.99。

将两个窗口的平方误差合并后，新增计算项岭回归的RMSE为1457.92，普通岭回归为1564.31，梯度提升树为1718.97。在五个参与回溯比较的方法中，新增计算项岭回归的合并RMSE和最差窗口RMSE都最低。两个时段共同支持该方案较低的合并误差和较小的最差窗口误差。

合并RMSE计算为：sqrt((73×第一窗口RMSE² + 73×第二窗口RMSE²) / 146)。这两个窗口沿用主验证期选择的参数，属于描述性回溯比较。

### 平均偏差

平均偏差按“预测量减实际量”计算。新增计算项岭回归为-78.77次/天，梯度提升树为-511.35次/天，普通岭回归为-23.08次/天。普通岭回归的整体偏差更接近0，新增计算项岭回归则在绝对误差和平方误差上更低。平均偏差呈现方向性误差，RMSE与MAE同时衡量偏差幅度，报告共同保留这些角度。

### 实现与解释

推荐方案由固定计算项和岭回归组成，共33个系数。平方项表达弯曲关系，乘积项表达两个因素的共同作用，月份周期项连接年末与年初。系数解释需要结合这些计算项。模型保存输入处理方法和学习到的系数，能够重新读取并恢复预测。

## 新模型误差复算

已使用Spark 3.5.7重新读取保存的新增计算项岭回归模型，对原110个测试日期重新执行预测；与该模型原始预测的最大差异为0。重新计算整体指标和天气、工作日、月份分组指标，并使用独立计算核对，结果一致。

## 汇报组织

验证集结果保留单次验证排名。测试集结果突出新增计算项岭回归的三项最优指标。跨时段比较补充合并RMSE、最差窗口和单个窗口差异。逐日误差与分组误差两页统一使用新增计算项岭回归。最后通过模型选择页综合说明准确性、跨期稳定性、解释与复现，以及新增日期验证的安排。

所有图表和表格沿用同一份731天数据及原日期划分。本次增加的是综合分析和新模型误差复算，原实验记录保留。
