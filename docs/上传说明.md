# 上传到 GitHub

当前目录已整理为独立的上传仓库，采用全新 Git 历史。源码、配置、说明和小型参考指标保留；下载数据、模型、运行结果和课件留在本地。

1. 在 GitHub 创建空仓库，取得自己的仓库地址。
2. 在本目录打开终端，检查并提交文件：

```bash
git status
git add .
git commit -m "Prepare reproducible Spark regression project"
git remote add origin <你的仓库地址>
git push -u origin main
```

如 Git 提示未设置作者身份，按提示配置自己的姓名与邮箱，再执行提交。源代码许可证由作者决定，可在公开前增加 `LICENSE`。

上传后打开仓库页面检查 README，并在另一目录下载源码运行 `python reproduce.py`。需要在汇报材料中提供资源链接时，使用实际仓库页面地址。

从原工作目录重新生成上传包可执行：

```bash
python scripts/prepare_github.py
```

脚本按文件清单导出，不复制旧 Git 历史。目标目录已存在时会停止，避免覆盖已修改的仓库；可使用 `--destination` 指定一个新目录。ZIP 仅包含上传文件。
